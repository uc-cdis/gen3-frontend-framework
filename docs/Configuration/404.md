# 404 Configuration Guide

The 404 page configuration consists of content section.

and example configuration:
```json
{
  "content": [
    {
      "type": "markdown",
      "text": "# 404: Page Not Found \n Sorry, we couldn&apos;t find the page you were looking for.",
      "className": "text-center"
    }
  ]
}
```

Cntent  is an array of the [TextContent](../../packages/frontend/docs/components/TextContent.md) component.
