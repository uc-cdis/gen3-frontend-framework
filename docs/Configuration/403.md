# 403 Configuration Guide

The 403 page configuration consists of two sections:
* Top icon
* content
* button

and example configuration:
```json
{
  "topIcon": {
    "src": "/icons/iconoir_window-no-access.svg",
    "alt": "No access"
  },
  "content": [
    {
      "type": "markdown",
      "text": "# 403: Not Authorized \n You are not authorized to access this page. If you believe this is an error, contact your administrator or support.",
      "className": "text-center"
    }
  ],
  "button": {
    "href": "https://sampleurl",
    "text": "Request Access",
    "variant": "outline"
  }
}
```
topIcon is for the icon to displayed at the top and consists of the image path and alt text
content  is an array of the [TextContent](../../packages/frontend/docs/components/TextContent.md) component.
button provides for a button centered at the bottom of the 403 page, variant is the styling variant as seen in the [mantine button compoent](https://mantine.dev/core/button/)
